# vto-eval

This repo compares general image models for virtual try-on. Each model receives two images and one text prompt through OpenRouter: a photo of a person and a photo of a garment. The model must put the garment on the person and keep the person and scene the same. We tested five models on 20 pairs on 14 October 2026. Hy Image 3.5 Preview gave the best results: all 20 outputs were usable, at $0.024 and 17 seconds per image. Seedream 5.0 Flash had the lowest cost for each usable image: 19 of 20 usable, at $0.018 and 15 seconds. FLUX.3 had good quality, but it took 70 seconds per image and blocked one request. Gemini 3.1 Flash Lite was the fastest at 7 seconds, but it often changed the pose or body of the person. FLUX.2 Klein 4B often added clothes from the product photo. The full table is in `results/2026-10-14-v1/summary.md`, and each grade has a note in `grades.json`.

An LLM (Claude Opus 5.5) graded all 100 outputs. A person did not grade them. The grading was blind: the script shuffled the outputs and hid the model names until all grades were complete. But one grader is not a strong reference, so do not trust small differences in score. Each model made only one output per pair, and most of these models do not accept a seed, so the results are not repeatable. The 20 pairs are small in number and difficult on purpose, so real catalog images will possibly give better results. We used one prompt for all models and did not tune it for each model. Latency changes with provider load, and we sent four requests at a time. Prices are OpenRouter list prices on the test date. The repo does not include the photos or the model outputs, because the outputs show real people with changes to their bodies and faces. To run the eval, add your OpenRouter key to `.env`, run `node scripts/fetch-dataset.mjs` to download the photos, and run `node run.mjs`. Then use `scripts/grading_sheets.py` and `scripts/summarize.py` to grade and summarize. The code has an MIT license, and the photos keep their Unsplash license.
